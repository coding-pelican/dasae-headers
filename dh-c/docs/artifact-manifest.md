# dh-c artifact manifest

`manifest.dh` is generated by dh-c for a concrete target/profile artifact directory.
It is output metadata, not a replacement for the user-authored `project.dh`.

## Location

Local builds:

```text
build/<normalized-target>/<profile>/manifest.dh
```

Packaged prebuilts:

```text
prebuilt/<normalized-target>/<profile>/manifest.dh
```

## Version 1 keys

```ini
manifest-version=1
target=x86_64-w64-windows-gnu
profile=stable
artifact-kind=static-lib
artifact=foo.lto.lib
lto=on
compiler=clang
```

A manifest records the normalized target, profile, artifact kind/name, effective LTO state,
and selected compiler spelling.

## Prebuilt compatibility

When a prebuilt package contains `manifest.dh`, dh-c validates:

- normalized target
- profile
- effective LTO state, when declared

An incompatible package is skipped in `prebuilt=auto` mode and rejected in
`prebuilt=required` mode.

Packages without a manifest are accepted as legacy packages during the migration period.
This compatibility path is intended to be removable after packaged SDKs have adopted the
manifest contract.
